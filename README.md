# Research Repository

研究・実験・シミュレーション・文献整理用リポジトリ。

## Overview

このリポジトリでは、研究に関連するコード・資料・メモ・実験結果を一元管理する。

主な内容：

- 光学・計算イメージング関連のシミュレーション
- 実験コード
- データ解析
- 文献管理
- 実験ログ・メモ
