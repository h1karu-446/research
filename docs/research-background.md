## 1. 研究テーマ・目的

**位相マスクと深層学習を用いたエリプソメトリー顕微鏡の焦点領域(DOF)拡張**

半導体や潤滑膜などの薄膜検査において、広い観察領域で高速にエリプソメトリー測定を行うための計算イメージング手法を開発する。

## 2. 解くべき課題(技術的ボトルネック)

- エリプソメトリー測定は原理上 **70〜80°の斜め照明が必須**(ブリュースター角付近で偏光変化が最大化されるため)。
- 斜め照明 → 光学的DOFが **約1μmまで狭くなる**。
- 実試料の表面凹凸は **200μmレンジ** が普通。
- 結果、試料表面のごく一部にしかピントが合わず、大部分が測定できない。

> 核心:「斜め照明必須」と「広い試料凹凸」の両立は光学だけでは原理的に不可能。ここを計算イメージングで突破するのが本研究。

### 従来手法の限界
- DOFが狭いためZ方向スキャンが必要になり、リアルタイム性が失われる。
- 絞りを絞る(NAを下げる)必要があり、光量低下・S/N比悪化を招く。
- DOF ∝ 1/NA² のトレードオフにより広視野化が困難。

### 期待される成果
- 焦点領域を 約1μm → 200μm に拡張
- 観察体積を 1.2 mm³ → 6.9 mm³ に増大
- Z方向スキャン不要の高速イメージング
- 学術的新規性: 計算イメージングのエリプソメトリー応用、斜め観察系への深層学習ベース光学設計の適用
- 産業インパクト: 半導体検査の高速化、インライン検査、低コスト実装(位相マスク<$10)

## 3. 研究の4本柱

| 柱 | テーマ | 役割 |
|---|---|---|
| **A** | 光学・エリプソメトリー原理 | 何を測りたいか(目的) |
| **B** | PSF・DOF | なぜ難しいか(課題の物理) |
| **C** | 計算イメージング(古典的手法) | どう解くか(本研究のコアアプローチ) |
| **D** | 深層学習・End-to-end設計 | もっとうまく解けるか(発展・修論方向) |

進行順: 柱A(目的理解) → 柱B(課題の物理理解) → 柱C(古典的解法、卒論コア) → 柱D(深層学習、修論方向)

### 柱A の要点(光学・エリプソメトリー)
- エリプソメトリー: 偏光した光を斜め(70〜80°)に試料に当て、反射光の偏光状態の変化(Ψ, Δ)から薄膜の屈折率・膜厚を逆算する測定技術。
- 垂直入射だとP偏光/S偏光の区別がつかず情報が取れないため、斜め入射が必須(特にブリュースター角付近で感度最大)。
- エリプソメトリー方程式: ρ = tan(Ψ)e^{iΔ} = r_p/r_s (r_p, r_sはフレネル反射係数)
- 研究上の位置づけ: エリプソメトリー自体はブラックボックスの測定手法として扱ってよく、解決すべきは「斜め照明必須」という制約が生む光学系のDOF不足。

### 柱B の要点(PSF・DOF)
- PSF(Point Spread Function): 点光源がレンズを通った後の光強度分布。瞳関数 P(ρ)=A(ρ)e^{iφ(ρ)} をフーリエ変換し絶対値二乗を取ったものがPSF。
- 位相マスクを設計する = PSFの形を設計する、と数式的に同値。
- デフォーカス位相: Φ_DF(ρ) = kW_mρ²(論文Eq.5)。マスクありの場合はここに位相マスクの位相Φ_maskが加算される。
- DOFの物理式: DOF ∝ λ/NA²。斜め観察では DOF = (垂直DOF) × sin(視野角) のように圧縮される。
- 研究の核心アイデア: 位相マスクでPSFのz方向の裾野を広げ(ぼけ方をなだらかにする)、DOFを拡張する。

### 柱C の要点(計算イメージング/古典手法)
- 核心アイデア「わざとぼかして後で戻す」: 全z位置で同じぼけ方(z不変PSF)にすれば、1回のデコンボリューションで全域を復元できる。
- Cubic Phase Mask(CPM): 位相がφ(x,y)=α(x³+y³)に従うマスク。位相の傾き(局所空間周波数)の曲率が固定され、デフォーカス量kW_mが変わっても波形が横にスライドするだけになるため、PSFがz方向にほぼ不変になる。
- 復元: Wienerフィルタ F̂(ω) = H*(ω)/(|H(ω)|²+K) × G(ω)。Kが正則化パラメータ(ノイズ耐性とボケ残りのトレードオフ)。
- 柱Cの限界(柱Dへの橋渡し): 位相マスクの形状もデコンボリューションも人間設計・従来手法であり最適とは限らない。エリプソメトリーの斜め照明への適用も難しい → 深層学習(柱D)でマスクと復元を同時最適化する方向へ。

## 4. 技術的課題の仮説(v0.4以降で検証予定)

(a) **PSFの非対称性**: 斜め照明下ではPSFが楕円・歪み形状になる可能性があり、CPMの「軸方向不変性」という前提が崩れるかもしれない。
(b) **偏光保存**: 位相マスクが複屈折性を持つと偏光状態を乱し、エリプソメトリー測定自体が成立しなくなる。等方的な位相マスク設計が必要。
(c) **スケールの壁**: 200μmレベルのDOF拡張は古典CPMの守備範囲外。古典手法だけでは不十分で深層学習(柱D)が必要という結論に至る可能性が高い(これ自体が研究成果になりうる)。

## 6. v0.1 実装内容(完了済み・詳細)

**目的**: フーリエ光学に基づく波動伝搬コードの動作確認(標準PSFシミュレーション、マスクなし)

- 参考コード: report_chang.pdfのEq.2〜6、およびDeepDOF(Jin et al. 2020)のDeepDOF_step2.pyの前半をNumPyに移植。
- 構成(6ブロック):
  1. パラメータ定義(λ, 格子サイズN_B=71, 離焦断面数N_PHI=21)
  2. 瞳座標とアパーチャ生成: `build_pupil_coords`, `build_aperture`
  3. デフォーカス位相生成: `gen_defocus_phase`(論文Eq.5, Φ_DF=kW_mr²)
  4. PSF計算(核心): `gen_psfs_no_mask`(論文Eq.2-6、Φ_mask=0)。瞳関数P=A·e^{iΦ}をFFT→fftshift→絶対値2乗→パーセバルの定理で正規化。
  5. 可視化(4種のグラフ: psf_grid, psf_grid_normalized, psf_profiles, peak_vs_defocus)
  6. `main()`(オーケストレーター)

**結果**:
- 全21断面でPSF合計がちょうど1.000000(エネルギー保存が正しく機能)
- ピント合焦時(kWm=0)のピーク強度0.764に対し、最大離焦時(kWm=±10)は8.68×10⁻⁴ — **約880倍の落ち込み**。マスクなし顕微鏡のDOFが極端に狭いことを定量的に裏付け。
- kWm=-10と+10でピークが完全対称(Φ_M=0でr²の偶関数のみのため妥当。v0.2でCPMが乗ると非対称になるはず)。

**レビューで見つかった懸念点(v0.2に引き継ぐべき事項)**:
1. **ガードバンドなし**: `build_aperture`の半径デフォルトが座標グリッド半幅と同じため、円形開口がグリッド端にぴったり接しており、ゼロパディングがない。kWm=±8〜10で本来リング状になるはずが、チェッカーボード状のノイズ(エイリアシングの疑い)が出現している。v0.2でCPMを乗せる前に、パディングありなしの結果を比較しておくと安心。
2. **PUPIL_HALF_WIDTH(=71/25≈2.84)の物理的根拠が不明**: DeepDOF本家のコードにも計算式のコメントのみで、NA・波長・センサピクセルサイズ等との関係が明示されていない。v0.1〜v0.3はこのまま踏襲するが、v0.4で物理単位(μm)を扱う際には独自に導出し直す必要がある。
3. **float32指定してもfloat64に格上げされる**: `phi_values`はfloat32だが`r2`(linspaceのデフォルト)がfloat64のため、型昇格規則で内部計算は実質float64。厳密管理したい場合は`r2`側もfloat32を明示するとよい。

## 7. v0.2 に向けて(次に着手する内容)

Notion「標準PSFのシミュレーション」ページの記載より:

> `gen_psfs_no_mask`の`phase = oof_phase`を`phase = oof_phase + phi_mask`に差し替えるだけでCPM(Cubic Phase Mask, φ(x,y)=α(x³+y³))を統合できる設計になっている。Zernike多項式パラメータ化を早期採用するかどうかは、「基底×係数→位相マップ」を返す関数を1つ追加する形で、既存構造を大きく崩さず導入できそうだと考えている。

- **目的**: CPMの本質(PSFの軸方向不変性)を可視化する。
- **追加要素**: 瞳面に立方位相 φ(x,y) = α(x³+y³) を加える。
- **出力**: マスクあり・なしでのPSFを軸方向(z)に並べた比較画像。
- **検証**: report_changのFig.に類似する形状が出るか。
- v0.1のガードバンド不足の懸念(上記6-1)は、v0.2着手前に一度確認しておくとよい。
